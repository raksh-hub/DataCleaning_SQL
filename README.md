# Nashville Housing Data Cleaning

A SQL data-cleaning project using the Nashville Housing dataset from Kaggle.

**Source:** [Kaggle — Nashville Housing Data](https://www.kaggle.com/datasets/tmthyjames/nashville-housing-data?utm_source=chatgpt.com)

## What I cleaned

* Standardized `SaleDate`
* Fixed inconsistent `LandUse` values
* Standardized `SoldAsVacant`
* Filled missing `PropertyAddress` values
* Cleaned and converted `SalePrice`
* Split property and owner addresses
* Removed duplicate records
* Removed unused columns

## Tools

* MySQL
* SQL
* CSV for data

## Skills Used

`JOIN` · `CTE` · `ROW_NUMBER()` · `CASE` · `REGEXP` · `SUBSTRING` · `SUBSTRING_INDEX` · `ALTER TABLE` · `UPDATE` · `DELETE` etc
